Welcome to AI Bake Fail Doctor

AI Bake Fail Doctor is a mini project designed to help users understand common baking failures. Upload a photo, select the problem you observe, and view possible causes and solutions based on baking science.

      💡 How It Works

      1. Upload a photograph of the failed baked item.
      2. Select the type of baked product.
      3. Choose the baking problem observed.
      4. View possible causes based on baking science.
      5. Follow the suggested solutions for the next baking attempt.

      📘 About the Project

      The objective of AI Bake Fail Doctor is to develop a system that can identify common baking defects and recommend suitable corrections. This prototype demonstrates the user interface and rule-based diagnosis process.

      Future development can include dataset collection, image preprocessing, training an image-classification model and connecting model predictions to baking recommendations.
