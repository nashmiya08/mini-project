          📘 About the Project

          AI Bake Fail Doctor aims to identify baking defects, explain their possible causes using baking science, and suggest recipe adjustments to improve future baking results.

          This initial version uses manually selected symptoms and rule-based suggestions. A trained image-classification model and a verified recipe knowledge base can be added after dataset collection and preprocessing.
