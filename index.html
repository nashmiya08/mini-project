        📚 About the Project

        AI Bake Fail Doctor is a baking troubleshooting project designed to help users understand common baking failures through baking science and practical recommendations.

        The current version is a rule-based prototype. A future version can integrate a trained image-classification model and a verified recipe database to support automatic defect detection and recipe-specific adjustments.
